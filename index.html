Sauvegarde & automatisation

Les modifications sont conservées dans ce navigateur. Exportez une sauvegarde avant de changer d'appareil ou d'effacer les données de navigation.

Actualisation automatique : sur GitHub Pages, le tableau charge data/opportunities.json à l'ouverture, puis lors du clic sur « Actualiser ». Le workflow GitHub Actions inclus peut interroger l'API France Travail chaque jour après configuration des identifiants API gratuits. Il ne scrute pas automatiquement LinkedIn ou l'intégralité des sites carrières. Les offres non confirmées sont signalées comme telles ; aucune admission d'étudiantes étrangères n'est présumée.
